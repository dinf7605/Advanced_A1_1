# 자동화

총 2개

## PRD 초안 요청 유저 프롬프트

```
아래 입력 템플릿을 바탕으로 PRD 초안을 작성해 주세요.
비어 있거나 모호한 항목이 있으면 먼저 확인 질문을 해주세요.

--- 입력 템플릿 시작 ---
[기능명] ...
[목적] ...
[대상 사용자] ...
--- 입력 템플릿 끝 ---
```

## PRD 입력 템플릿 (바코드 스캔 재고 등록)

```
[기능명] 바코드 스캔 재고 등록
[목적] 입고 시 수기 입력 오류 감소
[대상 사용자] 창고 입고 담당자 (입고 시 상시 사용)
[핵심 사용 시나리오] 스캔 → 상품정보 자동입력 → 수량 입력 → 등록
[성공 지표] 입고 등록 오류율 5% → 1%
[제약/정책] 전용 바코드 스캐너 사용
[톤] 간결·실무형
[금지어] '완벽하게', '100% 보장'
[필수 포함 항목] 목적/사용자/기능요구/수용기준/리스크
```
