============================================================
 프롬프트 관리 프로그램 PRD & 7일 실행 계획
============================================================
AI 프롬프트를 저장/조회/검색/즐겨찾기할 수 있는
Python 콘솔 프로그램 개발 계획서

------------------------------------------------------------
1. 프로젝트 개요
------------------------------------------------------------
- 이름      : Prompt Manager (프롬프트 관리 콘솔 프로그램)
- 목적      : 자주 쓰는 AI 프롬프트 저장/조회/검색/즐겨찾기 CLI
- 환경      : Python 3.10+ / 외부 라이브러리 미사용(필수 기능)
- 학습 목표 : Python 기초 문법 + Git/GitHub 워크플로우 체득
- 진행 방식 : 1인 개발 (혼자 진행)

------------------------------------------------------------
2. 핵심 기능 (MVP)
------------------------------------------------------------
[메뉴 출력]     show_menu()           - 번호 선택식 메뉴
[프롬프트 추가] add_prompt()          - 제목/내용/카테고리 입력
[목록 보기]     show_list()           - 전체 목록 + 즐겨찾기(*) 표시
[카테고리 조회] show_by_category()    - 카테고리별 필터
[검색]          search_prompt()       - 제목/내용 키워드 검색
[상세 보기]     show_detail()         - 전체 내용 출력
[즐겨찾기]      toggle_favorite() / show_favorites() - 추가/해제, 모아보기
[종료]                                - 프로그램 종료

------------------------------------------------------------
3. 데이터 구조
------------------------------------------------------------
# 프롬프트 1개 = 딕셔너리, 전체 = 리스트
prompts = [
    {"title": "블로그 작성", "content": "...", "category": "텍스트 생성", "favorite": False},
    {"title": "이미지 프롬프트", "content": "...", "category": "이미지 생성", "favorite": False},
    {"title": "페르소나 설정", "content": "...", "category": "페르소나", "favorite": False},
]

- 카테고리 예시 : 텍스트 생성, 이미지 생성, 영상 생성, 페르소나, 자동화, 기타
- 프롬프트 필드 : title(제목), content(내용), category(카테고리), favorite(즐겨찾기)

------------------------------------------------------------
4. 7일 실행 계획 (Day-by-Day)
------------------------------------------------------------

[Day 1] 환경 세팅 & 저장소 초기화
 - VSCode + Python 확장 설치, python --version 확인
 - print("Hello") 실행 테스트
 - Git 설정 (user.name, user.email, init.defaultBranch main)
 - GitHub 새 저장소 생성 -> 로컬 git init -> 원격 연결
 - .gitignore, README.md(제목만) 생성
 - 공개 저장소 하나 git clone 으로 받아 구조 확인 후 삭제
 - [스크린샷] 개발 환경(버전, Git 설정)
 - 커밋 1~2개: "chore: 프로젝트 초기 세팅", "docs: README 초안"

[Day 2] 기본 데이터 & 메뉴 골격
 - 기본 프롬프트 3개 이상 리스트에 등록
 - show_menu() 작성 + 메인 루프(while True) 구성
 - 잘못된 입력 처리, 종료 기능
 - (팁) 각 기능은 아직 "준비 중" 메시지만 출력해도 OK
 - 커밋 3~4개: "feat: 기본 데이터 등록", "feat: 메뉴 및 메인 루프 구현"

[Day 3] 추가 / 상세 보기 기능
 - add_prompt() (빈 입력 재요청, 즐겨찾기 기본 False)
 - show_detail() (번호 유효성 검사)
 - 커밋 5~6개: "feat: 프롬프트 추가 기능", "feat: 상세 보기 기능"

[Day 4] 목록 기능 (** 브랜치 실습 필수! **)
 - git checkout -b feature/list     # 브랜치 생성
 - show_list() 구현 + 커밋
 - git checkout main
 - git merge feature/list           # 병합
 - show_list() 를 feature 브랜치에서 작업 후 main 으로 merge
 - 커밋 7~8개: "feat: 목록 보기 기능"(브랜치), 병합 기록

[Day 5] 검색 / 카테고리 / 즐겨찾기
 - search_prompt()
 - show_by_category()
 - toggle_favorite(), show_favorites()
 - 커밋 9~11개: 기능별로 각각 커밋

[Day 6] 정리 & 문서화
 - 코드 리팩토링 (함수 분리 점검, 중복 제거)
 - README 완성 (설명/실행 방법/기능 목록/카테고리)
 - git pull 로 원격 동기화 실습
 - [스크린샷] 실행 결과, 검색 결과 등
 - 커밋 12개+: "refactor: 코드 정리", "docs: README 완성"

[Day 7] 마무리 & (선택) 보너스
 - git log --oneline --graph 확인 및 스크린샷
 - 최종 push
 - (여유 시) 보너스: JSON 저장/불러오기, CRUD
